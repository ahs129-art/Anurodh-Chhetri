# 🚗 OnRoad Type 🚦

Welcome to **OnRoad Type**, the ultimate typing test experience with a modern, cyberpunk twist! This exclusive project combines slick UI design, continuous typing challenges, and a dope music vibe to level up your typing skills. Get ready to cruise through paragraphs with style! 🎵💻

---

## 📝 Description

*OnRoad Type* is a web-based typing test tool designed to keep you engaged with its futuristic welcome screen, dynamic paragraph generation, and customizable music playback. Whether you're a beginner or a typing pro, this app brings a fresh, road-inspired feel to your practice sessions. Built with love by a passionate dev, it’s all about that goated experience!

---

## ✨ Features

- **Crazy Modern Welcome Screen**: Neon glow, glitch effects, and particle animations for a jaw-dropping first impression.
- **Continuous Typing Test**: Dynamically generated paragraphs that adapt to your test duration (15s, 30s, 60s) for endless typing.
- **MonkeyType-Style Error Highlighting**: Real-time feedback with green (correct) and red (error) text.
- **Auto-Playing Music**: Kick back with Mac Miller’s “Surf” (and space for 4-5 more tracks you can add!).
- **Multiple Music Sources**: Cycle through tracks with the "Play Next" button.
- **Repeat or Next Options**: Replay the same paragraph or get a fresh one after each test.
- **Dark/Light Mode**: Toggle between vibes with a click.
- **Past Results Tracking**: Save and view your typing stats locally.
- **Responsive Design**: Looks fire on any device!
